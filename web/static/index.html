📚 使用指南

1. 我是新手，先干什么？

打开首页 🔍 智能选股，用默认的"均衡型"风格，池子选沪深 300、取 20 只、下限 0，点"开始筛选"。约 30 秒后，你会看到综合评分最高的 10 只股票。

2. 综合评分是什么意思？

0-100 分，分越高越有短期上涨潜力。它由四个维度加权得到：

  • 技术面（K 线信号）：均线多头排列、有动量、量能配合。评价"最近走势好不好看"。
  • 基本面（财务健康）：估值不贵、盈利能力强、有增长。评价"公司质地怎么样"。
  • 资金面（谁在买）：北向资金增持、主力净流入、换手适中。评价"聪明钱在不在买"。
  • 情绪面（AI 分析公告）：AI 读近期公告，判断是利好还是利空。评价"最近有什么消息面"。

60 分左右为中性，70+ 为看好，80+ 为强烈看好。低于 40 建议回避。

3. 五种选股风格怎么选？

风格特点适合
均衡四维等权新手 / 不知道自己偏好
动量看重技术面 + 资金面短线波段爱好者
价值看重基本面（低估）价值投资 / 中长线
成长基本面 + 情绪并重找业绩爆发股
红利基本面（稳定）+ 资金长线拿分红

4. AI 情绪分析要不要开？

开了之后，AI 会去读每只股票近期公告并打分。效果好但慢（每只多 2-5 秒），也需要在设置里配 API Key（推荐 DeepSeek，便宜）。没配 Key 就别开，会一直显示 50 中性分。

5. 模拟账户怎么用？

  1. 去 💼 我的账户，起个名字（如 my_test），初始资金 10 万
  2. 点"新建账户"→ 点"运行今日策略"
  3. 策略会自动根据综合评分买入 Top 股票，含止损止盈
  4. 每天点一次"运行今日策略"，看收益怎么变

6. 常见问题

Q：所有股票评分都是 50？ 说明数据源暂时拉不到，晚点再试；或者你在墙内，AkShare 某些接口偶尔卡。

Q：LLM 情绪分永远显示 50？ 没配 API Key。去 ⚙️ 设置 填一个（DeepSeek 便宜）。

Q：这是投资建议吗？ 不是。只是一个个人研究工具，输出结果不构成任何投资建议，实盘请自行判断。
